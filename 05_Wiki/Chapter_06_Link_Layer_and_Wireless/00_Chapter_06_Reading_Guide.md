# 📖 Chapter 06: Link Layer & Wireless Networks (Study & Reading Guide)

> [!IMPORTANT]
> **เป้าหมายของบทนี้:** ทำความเข้าใจบริการของ Data Link Layer (Framing, Flow/Error Control, Half/Full Duplex), การตรวจจับข้อผิดพลาดด้วย **CRC (Cyclic Redundancy Check) Polynomial Division**, Multiple Access Protocols (CSMA/CD ในสาย และ CSMA/CA ในไร้สาย), MAC Addressing (48 บิต) และ ARP Protocol, โครงสร้างสวิตช์อีเทอร์เน็ตและการเรียนรู้ MAC Table อัตโนมัติ, การแบ่งเครือข่ายเสมือน **VLAN (IEEE 802.1Q)**, และเทคโนโลยีเครือข่ายไร้สาย Wi-Fi 802.11 / Bluetooth
