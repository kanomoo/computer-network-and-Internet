### 2. สูตรและขั้นตอนการคำนวณ Dijkstra's Algorithm (จากประกาศอาจารย์)
* เตรียมตาราง $N'$, source node
* ลูป: เลือก node ที่มี cost ต่ำสุดเข้า $N'$ -> Update เพื่อนบ้าน $D(v) = \min(D(v), D(u) + c(u,v))$
